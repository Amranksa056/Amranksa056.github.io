# Quiz Earn

**Quiz Earn** is a quiz-based rewards app where users can test their knowledge, answer questions, and earn rewards according to the app’s rules.

## About

This repository is used for the **Quiz Earn** app’s GitHub Pages site and hosts its `app-ads.txt` file for advertising partner verification.

## App

- **Name:** Quiz Earn
- **Purpose:** Answer quizzes and collect in-app rewards
- **Platform:** Android

## Advertising

The `app-ads.txt` file is published at the root of this GitHub Pages site. Keep it up to date with the authorized advertising sellers for the app.

## Important

Rewards, eligibility, and redemption are subject to the app’s terms and availability. Please use the app responsibly and review its rules before participating.
